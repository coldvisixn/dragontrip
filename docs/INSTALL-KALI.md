# Установка Dragontrip на Kali Linux

[English installation guide](INSTALL.md) · [Описание проекта](../README.ru.md)

## Скачать готовый пакет

Откройте [Releases → v0.9.1](https://github.com/coldvisixn/dragontrip/releases/tag/v0.9.1). В разделе **Assets** скачайте:

- **`dragontrip_0.9.1_amd64.deb`** — установщик приложения.
- **`dragontrip_0.9.1_amd64.deb.sha256`** — контрольную сумму этого файла.

Архивы **Source code (zip/tar.gz)** — исходники для разработчиков, а не готовая программа. Артефакты Actions нужны для тестовых сборок; обычное скачивание находится в Releases.

Версия 0.9.1 — prerelease (ранний MVP) для Linux x86_64. Проверьте архитектуру командой `dpkg --print-architecture`: нужна `amd64`. Сборок для ARM, Windows и macOS сейчас нет. Перед публикацией установщик проверяется на Ubuntu, затем именно этот пакет устанавливается на Kali и проходит нативные тесты. Отдельно проверяется сохранность данных и зашифрованных credentials при обновлении с опубликованных 0.8.0 и 0.9.0. [Точные результаты и ограничения](BUILD-0.9.1.md). Проверка настоящей VirtualBox VM остаётся отдельной.

## Проверить и установить

Откройте терминал в папке с обоими скачанными файлами:

```bash
sha256sum --check dragontrip_0.9.1_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.9.1_amd64.deb
```

Контрольная сумма должна дать `OK`. Если проверка не прошла, заново скачайте оба файла из одного релиза. SHA-256 проверяет целостность файла; отдельной цифровой подписью он не является.

Для recon установите нужные инструменты из репозитория Kali:

```bash
sudo apt install nmap whatweb httpx-toolkit ffuf
```

Нужен **ProjectDiscovery httpx** — на Kali это пакет `httpx-toolkit`. Одноимённая Python-библиотека его не заменяет. Отсутствующие инструменты отображаются как недоступные в **Tools**; пути можно задать в **Settings**.

Python-бэкенд и его зависимости входят в пакет. Node.js, Rust, pip и Docker для запуска готовой программы не нужны. Зависимости GTK/WebKit устанавливает APT.

## Запустить и начать работу

Откройте **Dragontrip** из меню приложений или выполните:

```bash
dragontrip
```

1. Создайте проект.
2. В **Project overview** выберите **Import results**, **Define target scope** или **Start live recon**. Для знакомства можно явно создать отдельный вымышленный демопроект.
3. Откройте хост или сервис в графе: в **Inspector** доступны сведения и исходное evidence.
4. Добавьте заметку или находку и свяжите её с объектами и доказательствами.
5. Создайте задачу в **Task board**, проверьте прогресс в **Project overview** и сформируйте отчёт в **Reports**.

Подробный [user guide](USAGE.md) описывает разделы и основной сценарий. Интерфейс приложения сейчас на английском. `Ctrl+K` открывает палитру команд, `Ctrl+Shift+F` — поиск по знаниям.

## Обновить

Закройте приложение и сохраните копию всей папки `${XDG_DATA_HOME:-~/.local/share}/dragontrip/`. Затем скачайте новый `.deb` и его SHA-256 из одного релиза, проверьте сумму и установите пакет через APT. Миграции запускаются автоматически.

Не открывайте обновлённую базу старой версией программы. Для отката нужна соответствующая резервная копия до обновления. Текущие архивы используют формат v5 для рабочего контекста, черновиков и ретестов; импорт читает v1–v5. Старое приложение не прочитает v5.

**Projects → Project portability** переносит проект в `.dtproj`. Credentials включаются только явно, с отдельным паролем архива и разблокированным локальным Vault. Это отдельный сценарий от резервной копии всей папки данных. [Данные и backups →](DATA.md)

## Удалить

```bash
sudo apt remove dragontrip
```

Удаление пакета сохраняет пользовательские проекты. Данные каждого Linux-пользователя хранятся отдельно.

## Если что-то не работает

- **Нет установщика:** раскройте **Assets** в Releases; не используйте архив Source code вместо `.deb`.
- **Ошибка зависимостей:** устанавливайте через `sudo apt install ./...deb` на обновлённой поддерживаемой системе; не подменяйте вручную GTK/WebKit несовместимыми версиями.
- **Не виден scanner:** установите системный инструмент, проверьте **Tools** и абсолютный путь в **Settings**.
- **Пустое окно:** запустите `dragontrip` из терминала и приложите ошибку, версию дистрибутива и WebKit к [bug report](https://github.com/coldvisixn/dragontrip/issues/new?template=bug_report.yml). Уберите секреты и данные целей из вложений.
- **На машине с подходящим GPU:** можно попробовать `DRAGONTRIP_HARDWARE_ACCELERATION=1 dragontrip`. По умолчанию используется режим без аппаратного ускорения для небольших VM.
- **Забыт мастер-пароль Vault:** восстановления нет. Не удаляйте имеющуюся резервную копию.
