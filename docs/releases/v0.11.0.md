# Dragontrip 0.11.0 — Русский интерфейс и плавная навигация

## Что изменилось / What's new

- **English ↔ Русский.** Откройте **Settings → Interface language** / **Настройки → Язык интерфейса**. Язык применяется сразу и автоматически сохраняется для всех проектов. Переведены меню, разделы проекта, формы, статусы и доступные подписи; формат дат соответствует выбранному языку.
- **Плавные переходы.** Короткие переходы вкладок и внешнего вида сохраняют состояние редакторов и черновиков.
- **Работающее уменьшение движения.** «Уменьшить движение» действует сразу для предпросмотра; нажмите «Сохранить внешний вид», чтобы оставить настройку. Низкий профиль производительности и системная настройка уменьшения движения также отключают анимации.
- **Сохранность содержимого.** Названия проектов, авторские записи, секреты, исходные свидетельства и вывод инструментов сохраняют исходный текст. Перевод подписей не меняет значения API или маршруты.

Switch between English and Russian in Settings. The language is saved automatically for every project. Tab and appearance transitions preserve editors and respect Reduce motion, Low rendering cost and system preferences. Save appearance to retain motion changes. Authored text and original tool evidence retain their content.

## Установка / Download and upgrade

В **Assets** скачайте **dragontrip_0.11.0_amd64.deb** и **dragontrip_0.11.0_amd64.deb.sha256**. Автоматические Source code-архивы не являются установщиками.

```bash
sha256sum --check dragontrip_0.11.0_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.11.0_amd64.deb
dragontrip
```

Закройте приложение и сохраните полную резервную копию каталога данных перед обновлением. Схема БД остаётся **0006**, формат экспорта — **v6**, импорт читает **v1–v6**. В этой версии нет новой миграции. Для отката используйте соответствующую резервную копию.

Close Dragontrip and back up the complete data directory before upgrading. Database schema 0006 and archive v6 remain unchanged; imports accept v1–v6. The installer bundles the frontend and Python backend; recon tools are installed separately.
