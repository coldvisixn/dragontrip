# Dragontrip 0.10.0 — Keep the investigation moving

A connected workspace from project goal and scope to discovery, web research, evidence, follow-up tasks, findings and retests.

## What changed

- **Plan your investigation.** Set a project goal, define scope and see a suggested next step. The sidebar groups Plan, Research, Recon and Notebook; every page remains accessible without a More menu.
- **Keep the selected object.** Hide Inspector without losing selection. Explore web endpoints and their details side by side; carry an observed HTTP service into web research without sending requests.
- **Find the result.** Background work shows queue/execution/saved-result state. Open the result, export evidence, stop work or review a new attempt; technical output is available on demand.
- **Approve the actual plan.** Backend-validated profiles and scope precede network authorization. Repeated requests with the same launch receipt return the existing scan instead of creating duplicate traffic.
- **Keep partial evidence.** Failed and cancelled runs retain bounded artifacts and safely parseable observations. Incomplete coverage does not falsely close previously observed services. Restart never silently resumes network work.
- **Recover your context.** Stale project responses cannot replace the active workspace; linked notes, tasks, findings, retest history and existing draft recovery stay connected.
- **Choose rendering cost.** Low, Medium and High profiles control graph detail and decoration. Medium retains previous defaults; reduced motion, virtualization and large-graph limits remain available.

## Download and upgrade

Download **dragontrip_0.10.0_amd64.deb** and **dragontrip_0.10.0_amd64.deb.sha256** from Assets. GitHub's source archives are not installers.

```bash
sha256sum --check dragontrip_0.10.0_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.10.0_amd64.deb
dragontrip
```

Close Dragontrip and back up the complete data directory before upgrading. Migration **0006** adds an empty project goal without changing existing descriptions. New project archives use **v6**; imports read **v1–v6**. Older applications cannot open v6 exports. Rollback requires the matching pre-upgrade backup. Ordinary notes, evidence and drafts remain unencrypted; Vault credentials use the existing encrypted transfer mechanism.

## Validation and limits

Publication is gated by backend/frontend checks, packaged-backend tests, upgrades from published releases, native Tauri/WebKit checks and installation of the exact package on Kali Rolling. The installer contains the frontend and Python backend; recon tools are installed separately.

Linux x86_64, English interface, 0.x prerelease. Physical/VirtualBox performance is not established by container checks. Native high-percentile frame delays on larger graphs remain a documented limitation. Retests record manual verification history; automatic HTTP-body/screenshot diff and resuming inside a stopped external process are not included.
