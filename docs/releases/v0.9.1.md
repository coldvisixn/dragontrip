# Dragontrip 0.9.1

Security and maintenance release for the local Linux investigation workspace.
Install this version to receive the fixes made after 0.9.0. The existing
investigation, recon, recovery, vault and report workflows are preserved.

## Fixes

- Count received API body bytes, including streamed requests, and enforce request/upload budgets before parsing excess data.
- Exclude password, credential and malformed-document input from validation responses; handle malformed Host and authorization headers safely.
- Update vulnerable backend and development dependencies. Backport the upstream GLib iterator fix used by GTK 3, with source-provenance checks and optimized regressions.
- Reconcile the outstanding dependency PRs as compatible sets: Pydantic/core, Vite/React plugin, test tools, packaging tools and CI actions. Adapt session-token generation to getrandom 0.4.
- Monitor future advisories for the original registry baseline of the GLib backport. A remaining build-tool maintenance warning is documented in the security audit; no advisory is silently suppressed.

## Download and update

Download `dragontrip_0.9.1_amd64.deb` and its `.sha256` from this release's **Assets**.
The automatic source-code archives are not installers.

```bash
sha256sum --check dragontrip_0.9.1_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.9.1_amd64.deb
dragontrip
```

Close Dragontrip and back up the complete data directory before upgrading.
There is no new database migration or archive-format change in 0.9.1. The release
pipeline verifies records, retests, original evidence, encrypted vault credentials
and draft recovery using the published 0.8.0 and 0.9.0 backends as upgrade baselines.
Portable exports remain v5 and imports read v1–v5. Ordinary notes/evidence/drafts
are not encrypted; the credentials vault is encrypted separately.

## Verification and supported scope

Publication is gated by backend/UI checks, frozen-backend restart checks, optimized
GLib tests, native WebKit acceptance and installation/native checks of the exact
release package on Kali Rolling. Checksums identify the published build's bytes.

Linux x86_64 (`amd64`) installer; English interface; 0.x prerelease/early MVP.
Windows, macOS and ARM installers are not provided. Containers do not establish
performance in a particular VirtualBox VM. Existing scope/import/report limits
remain documented in the user guide.
