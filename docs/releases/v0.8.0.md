## Dragontrip 0.8.0 — From recon to report

Your local pentest workspace now carries work through to a reviewed deliverable: recover drafts, document findings with evidence, record retests and export a self-contained report.

### What's new

- **Keep your work:** recover note, finding and manual-plan drafts across navigation and restart. Report summary/options persist per project. Stale record edits fail explicitly.
- **Start clearly:** new-project import/scope/recon actions, fewer empty metrics, editable project details and a separate opt-in fictional demo that runs no scans.
- **Document findings:** a blank reproduction/impact template, screenshot paste/file drop and append-only manual retest history. Fixed resolves; still present confirms; inconclusive retains status.
- **Deliver the result:** confirmed-first and working presets; Markdown, standalone HTML and ZIP with explicitly selected evidence. Changed content requires a fresh preview. HTML escapes raw markup and makes no external image/font requests.

Also includes the scope/import/web-map, manual methodologies, guided recon sequences and grouped navigation introduced since the published 0.5.0 preview. Nmap XML, Burp saved-items/issue XML and HTTP Nuclei JSONL imports preserve original evidence. Live recon uses the existing Nmap/WhatWeb/ProjectDiscovery httpx/ffuf queue.

### Install

Under **Assets**, download **`dragontrip_0.8.0_amd64.deb`** and **`dragontrip_0.8.0_amd64.deb.sha256`**. Source-code archives are not desktop installers.

```bash
sha256sum --check dragontrip_0.8.0_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.8.0_amd64.deb
dragontrip
```

Linux x86_64 (`amd64`), primarily current Kali Linux. The backend is bundled: Node.js, Rust, pip and Docker are not runtime requirements. Optional Kali recon tools: `sudo apt install nmap whatweb httpx-toolkit ffuf`. The httpx adapter requires ProjectDiscovery httpx.

### Compatibility and limits

**Close Dragontrip and back up the complete data directory before upgrading.** Archive format v4 retains retests; v1/v2/v3 imports remain supported. Older apps reject v4. Do not edit upgraded data with an older binary. Drafts are unencrypted, stay on this device and are excluded from project transfers/reports. Save records before transferring them.

This is an **early MVP / Pre-release**. Selected report evidence is limited to 100 files / 32 MiB; review it for sensitive data. Vault records, editor drafts and raw scan buffers are excluded. Native PDF/DOCX, live hostname/CIDR/IPv6 scanning, a crawler, automatic finding correlation and automatic exploitation are not implemented. The interface is in English; Windows/macOS/ARM installers are not provided.

### Verification

Local tests include backend/UI suites, a real frozen-backend browser workflow and an installed Debian Tauri/WebKit acceptance with native IPC, full restart recovery, evidence upload, retest and ZIP export. The tag workflow builds its own installer, runs checks and packaged planning/research/methodology/navigation/delivery acceptance, and verifies metadata/checksums before publishing. Use the checksum attached to this release; local and CI package bytes can differ.
