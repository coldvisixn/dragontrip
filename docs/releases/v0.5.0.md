## Dragontrip 0.5.0 — Investigation planning and reporting

An early-preview desktop workspace for authorized assessments, with recon, an infrastructure graph, evidence, findings and follow-up work in one local project.

### Download

Expand **Assets** and download **`dragontrip_0.5.0_amd64.deb`** plus **`dragontrip_0.5.0_amd64.deb.sha256`**. The automatic **Source code** archives are for developers, not desktop installers.

For Linux x86_64 (`amd64`), intended primarily for current Kali Linux:

```bash
sha256sum --check dragontrip_0.5.0_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.5.0_amd64.deb
dragontrip
```

On Kali, install the system recon tools you want to use with `sudo apt install nmap whatweb httpx-toolkit ffuf`. The package includes the Python backend; Node.js, Rust, pip and Docker are not needed to run it.

### What's new

- **Task board:** five statuses, priorities, owners, deadlines, templates and graph-object links; searchable and included in project archives.
- **Project overview:** work completion, overdue tasks, inventory, scan outcomes and active findings by severity.
- **Markdown reports:** executive summary, finding status/severity filters, remediation, optional sections, preview and private Downloads export.
- **Project presentation:** English/Russian README, installation/user/data guides, changelog and contribution/issue templates.

Includes the existing recon queue, Nmap/WhatWeb/ProjectDiscovery httpx/ffuf adapters, infrastructure graph, Markdown knowledge, evidence attachments, Timeline/search, encrypted vault and portable `.dtproj` projects.

### Verification and compatibility

The release workflow builds from this tag, runs backend/UI tests, checks the frozen backend and package checksum, and exercises planning/reporting in the packaged Tauri/WebKit application before publishing. Separate [local Debian verification](https://github.com/coldvisixn/dragontrip/blob/v0.5.0/docs/BUILD-0.5.0.md) covers installation, launcher, real loopback recon, graph, export/import and restart. The published CI artifact may have a different checksum from the earlier local build; always use the checksum attached here.

**Back up the complete data directory with Dragontrip closed before upgrading.** Task-containing archives require the updated importer. Do not open an upgraded database with an older binary; rollback requires a matching backup.

This is an early 0.x preview, not a promise of compatibility/performance on every Kali/VirtualBox setup. Windows, macOS and ARM packages, CIDR/IPv6/hostname scope, automatic exploitation and PDF/HTML reports are not provided. Report composition resets when leaving the report page.
