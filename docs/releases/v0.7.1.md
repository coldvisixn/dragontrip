## Dragontrip 0.7.1 — Connect your assessment

From recon output to findings with traceable evidence: a local, open-source pentest workspace for Linux. This MVP brings infrastructure, web applications, review coverage and follow-up work into one project.

### Since the published 0.5.0 preview

- **Bring your results:** preview and import Nmap XML, Burp saved-items/issue XML and HTTP Nuclei JSONL. Preserve original source files, inspect observations and compare imports.
- **Map the application:** navigate web origins and method-specific endpoints, parameters, linked findings and evidence alongside the infrastructure graph.
- **Define scope:** record IP, CIDR, domain and origin include/exclude rules. Offline support for these forms does not enable live hostname/CIDR/IPv6 recon.
- **Track review coverage:** use four-state web/service methodologies with saved notes and evidence links. Tool results never mark manual checks as tested.
- **Guide recon:** save ordered actions, preview scope and parameters, then explicitly launch each step through the existing queue. Retain run snapshots and cancellation history.
- **Move faster:** eight sidebar destinations, section tabs, remembered sections, keyboard navigation and a persistent compact sidebar replace the flat menu.
- **Keep development verifiable:** unified checks, linting, formatting, dependency updates and separate desktop/Kali acceptance jobs.

Includes existing notes, findings, attachments, encrypted credential vault, task board, Markdown reports and portable projects.

### Download and install

When this release is published, **Assets** contains `dragontrip_0.7.1_amd64.deb` and `dragontrip_0.7.1_amd64.deb.sha256`. Source-code archives are for development.

```bash
sha256sum --check dragontrip_0.7.1_amd64.deb.sha256
sudo apt update
sudo apt install ./dragontrip_0.7.1_amd64.deb
dragontrip
```

Linux x86_64 (`amd64`) only. The backend is bundled; Node.js, Rust, pip and Docker are not required to run the package. On Kali, install optional recon tools with `sudo apt install nmap whatweb httpx-toolkit ffuf`. The httpx adapter uses ProjectDiscovery httpx.

### Compatibility and current limits

Back up the complete Dragontrip data directory with the app closed before upgrading. Do not reopen an upgraded database with an older binary. New `.dtproj` archives use format v3; the importer also reads v1/v2. Older applications reject v3. Application-wide custom scan profiles are not included in project archives.

This is an early MVP, not a stable release. Reports export Markdown; HTML/PDF export, report-composition persistence, finding retest history, live domain/CIDR/IPv6 scanning, a crawler and automatic exploitation are not implemented. Supported imports are specific XML/JSONL formats, not binary `.burp`, HAR or Nessus.
